#Dataset

This project uses the CICIoMT2024 dataset, provided by the Canadian Institute for Cybersecurity at the University of New Brunswick. The dataset contains IoMT network traffic, including benign activities and various cyberattacks.

Dataset link: https://www.kaggle.com/datasets/limamateus/cic-iomt-2024-wifi-mqtt

The dataset is used to evaluate the effectiveness of the proposed PoisonGuard system in detecting and mitigating label-flipping data poisoning attacks in machine learning-based intrusion detection systems.
