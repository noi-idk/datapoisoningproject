## Research Papers

This folder contains *Proposal Report* and *Final Report*, which include the research papers and academic references used for the literature review of the PoisonGuard project.

### The papers cover:
1. Label-flipping attacks against machine learning models.
2. Data poisoning in intrusion detection systems.
3. Defence mechanisms for detecting and mitigating poisoned training data.
4. Machine learning security in IoT and healthcare environments.
